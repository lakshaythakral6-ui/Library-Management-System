#Library Management System

A C++ based Library Management System developed using Object-Oriented Programming (OOPS) concepts. This project helps manage books, students, book issuing, returning, searching, and transaction records.

#Project Objective

The main objective of this project is to simplify library operations and maintain book and student records efficiently.

#Features

- Add and manage books
- Search for books
- Register students
- Issue books to students
- Return issued books
- Maintain transaction records
- Store data using file handling

#Technologies Used

- **Programming Language:** C++
- **Database:** MySQL (separate SQL implementation)
- **Concepts:** Object-Oriented Programming (OOPS)
- **Storage:** File Handling

#OOPS Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Constructors

#Project Files

- `main.cpp` – Main C++ source code
- `library_management.sql` – SQL database implementation
- `Project_Report.pdf` – Project documentation

#How to Run

1. Download or clone this repository.
2. Open `main.cpp` in a C++ compiler.
3. Compile and run the program.
4. Follow the menu displayed on the screen to use the system.

**Note:** The C++ file-handling application and SQL implementation are separate; they are not currently integrated.
